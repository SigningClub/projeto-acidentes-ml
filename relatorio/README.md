# Relatório técnico

O relatório técnico (resumo, 12 seções e referências ABNT, com 4 figuras e 2 tabelas) foi redigido como documento editável:

**[Relatório Técnico — Previsão da Gravidade de Acidentes (PRF)](https://claude.ai/artifact/6cuMLDu9TenXx8oGEAM7aG)**

Para a entrega:

1. Abra o documento e use **Exportar → Word** (ou PDF).
2. Transponha o texto para o modelo oficial de relatório da disciplina.
3. Preencha instituição, autores e o link deste repositório.
4. Salve o arquivo final nesta pasta (ex.: `relatorio_tecnico.pdf`).

Todos os números do relatório vêm de `reports/resultados.md` e `reports/tables/`, gerados por `python -m src.evaluate`.
